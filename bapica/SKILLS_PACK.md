# Bapica Skills Pack — Adapté depuis Shubham Sharma

## 🧪 QA & Tests
**Skill**: Test Automatique
Déclenche une batterie de tests sur Bapica (100 scénarios multi-agents).
Usage: `npx tsx scripts/run-agent-tests.ts`

## 🚀 Déploiement
**Skill**: Ship
Workflow complet: build → lint → commit → push → deploy Vercel.
`npm run build && git add -A && git commit -m "fix: ..." && git push && vercel --prod`

**Skill**: CSO

## 🏗️ Architecture
**Skill**: Plan CEO
Rapport stratégique Bapica: features actives, RAG, intégrations, bugs, roadmap.

## 💻 Code Review
**Skill**: Review

## 🐛 Débogage
**Skill**: Investigate
